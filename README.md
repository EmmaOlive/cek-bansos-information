# Cek Bansos – Indonesian Social Assistance Information Guide

Social assistance programs play an important role in supporting eligible individuals and families in Indonesia. Understanding these programs and accessing reliable information can help people become more familiar with available public resources.

## Topics Covered

- Indonesian social assistance programs
- Program Keluarga Harapan (PKH)
- Bantuan Pangan Non Tunai (BPNT)
- DTKS information
- Social assistance eligibility categories
- Digital public information resources

## Online Resource

For additional information about Indonesian social assistance programs, [visit website](https://cek-bansos.id/).

## Purpose

This repository serves as an educational resource for organizing information about Indonesian social assistance programs and improving access to useful digital information.
